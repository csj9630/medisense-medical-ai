# OCR 변환 결과 수동 저장 버튼 개선 보고서

- 작업일: 2026-08-31
- 작업 영역: Admin OCR / Frontend
- 대상 기능: 이미지·문서 변환 및 청킹 결과의 VectorDB 수동 저장
- 변경 원칙: 분석과 저장을 분리하고 사용자가 저장 버튼을 눌러야만 벡터화·DB 저장 실행

---

## 1. 문제점

기존에도 VectorDB 저장 기능은 연결되어 있었지만 저장 버튼이 오른쪽 결과 패널의 추출 텍스트,
Chunk 목록, 품질 메모 아래에 위치했다. 결과가 길면 버튼을 발견하기 어려워 별도 저장 동작이
없는 것처럼 보일 수 있었다.

---

## 2. 변경 내용

- 저장 버튼을 긴 결과 미리보기에서 제거했다.
- 왼쪽 문서 작업 영역의 분석 버튼 바로 아래에 `청킹 결과 벡터화 및 저장` 영역을 추가했다.
- 문서 분석 전에도 버튼 위치를 보여주되 비활성화한다.
- 선택 문서의 OCR 변환과 청킹이 완료된 경우에만 저장 버튼을 활성화한다.
- 저장 중에는 회전 아이콘과 `벡터화 및 저장 중...` 상태를 표시한다.
- 저장 성공 후에는 `VectorDB 저장 완료`와 `저장됨` 배지를 표시하고 재클릭을 차단한다.
- 저장 실패 시 오류 메시지를 표시하며 다시 시도할 수 있다.
- 여러 문서를 분석했을 때는 현재 선택한 문서의 `jobId`만 저장한다.

화면 안내 문구를 다음과 같이 추가했다.

```text
이 버튼을 클릭하기 전에는 변환 결과가 VectorDB에 저장되지 않습니다.
```

---

## 3. 실행 흐름

```text
이미지·문서 선택
→ 문서 분석 테스트 클릭
→ OCR 변환 + 텍스트 정제 + Chunk 생성
→ 선택 문서 저장 버튼 활성화
→ 사용자가 VectorDB 저장 버튼 클릭
→ POST /api/admin/ocr/vector-save
→ 완료 Job의 Chunk Embedding 생성
→ 문서·Chunk·Embedding Transaction 저장
→ 저장 완료 상태 표시 및 중복 클릭 차단
```

분석 완료만으로는 Embedding이나 VectorDB 저장을 실행하지 않는다.

## 4. 변경 파일

| 파일 | 변경 내용 |

| `frontend/src/features/admin/components/ocr/OcrPanel.tsx` | 독립 저장 영역과 저장 상태 UI 추가 |

Backend의 기존 `/api/admin/ocr/vector-save`와 Transaction 저장 흐름은 변경하지 않았다.
