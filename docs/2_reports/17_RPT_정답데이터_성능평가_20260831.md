# 정답 데이터 기반 성능 평가 작업 완료 보고서

- 작업일: 2026-08-31
- 작업 영역: Frontend / FastAPI / AI Evaluation / Tests
- 대상 기능: 정답 데이터 업로드·직접 입력과 답변 성능 평가
- 지원 형식: JSON, JSONL, CSV, TXT, 직접 입력 텍스트
- 평가 지표: Exact Match, Token F1, 문자 유사도
- 제외 범위: 외부 LLM 자동 호출, 평가 데이터 영구 저장, 의미·의학적 정확성 자동 판정

---

## 1. 작업 목적

기존 `/evaluation` 화면은 제목만 표시하고 Backend Evaluation Router도 비어 있어 실제 평가를
수행할 수 없었다. 정답 데이터를 파일로 업로드하거나 화면에서 직접 입력한 뒤, 케이스별 모델
답변과 비교해 문자열 기반 성능지표를 확인할 수 있도록 전체 실행 흐름을 구현했다. 같은 패널을
어드민의 `성능 지표` 탭과 `/evaluation` 화면에서 함께 사용하며 기존 검색 평가 기능은 유지했다.

---

## 2. 최종 실행 흐름

```text
성능 평가 화면
→ JSON·JSONL·CSV·TXT 파일 또는 직접 입력 텍스트 선택
→ POST /api/evaluations/ground-truth/parse
→ UTF-8·확장자·파일 크기·항목 수·필수 정답 검증
← 질문·정답 Case 목록
→ Case별 모델 답변 입력
→ POST /api/evaluations/answers/run
→ AI Evaluation Metric 계산
← 평균 점수와 Case별 점수
→ 화면에 Exact Match·Token F1·문자 유사도 표시
```

정답과 모델 답변은 평가 요청 동안만 처리하며 DB나 파일 시스템에 저장하지 않는다.

---

## 3. 입력 형식과 제한

파일 입력은 다음 컬럼 이름을 인식한다.

| 구분 | 지원 Key/Header |
|---|---|
| 질문 | `question`, `query`, `질문` |
| 정답 | `expected_answer`, `expectedAnswer`, `ground_truth`, `answer`, `정답` |

직접 입력 예시:

```text
질문: 감기의 대표적인 증상은 무엇인가요?
정답: 기침, 콧물, 인후통, 발열 등이 나타날 수 있습니다.
---
질문: 충분한 수분 섭취가 중요한 이유는 무엇인가요?
정답: 탈수를 예방하고 신체 기능 유지에 도움을 주기 때문입니다.
```

- 여러 항목은 `---` 줄로 구분한다.
- `질문<TAB>정답` 또는 `질문|정답` 형식도 지원한다.
- 구분자 없는 일반 텍스트는 질문 없는 단일 정답으로 처리한다.
- 파일은 UTF-8, 최대 2MB이며 한 번에 최대 200개 항목을 평가한다.
- 정답과 모델 답변은 항목당 최대 20,000자다.

---

## 4. 평가 지표

| 지표 | 계산 기준 |
|---|---|
| Exact Match | Unicode·대소문자·연속 공백 정규화 후 완전 일치 |
| Token F1 | 한국어·영문·숫자 Token의 Precision/Recall 조화 평균 |
| 문자 유사도 | 정규화된 전체 문자열의 Sequence 유사도 |

세 지표는 문자열 비교용이다. 표현은 다르지만 의미가 같은 답변이나 의학적으로 올바른 답변인지
여부를 판정하지 않으므로, 결과 화면에도 이 한계를 명시했다.
